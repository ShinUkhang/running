# 🏃 학생 스마트 러닝 트래커 & 구글 스프레드시트 실시간 연동 시스템

학생들이 스마트폰, 태블릿, PC 브라우저에서 위치 정보(GPS)에 동의하고 러닝/운동을 측정하면, 실시간 지도 경로 표시와 함께 출발/종료시간, 운동시간, 거리, 소모 열량, 페이스가 계산되어 **구글 스프레드시트에 실시간 자동 기록**되는 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

1. **위치 정보(GPS) 동의 및 자동 추적**
   - 첫 실행 시 위치 정보 동의 모달을 통해 간편하게 동의 후 측정 시작
   - 화면 꺼짐 방지(Wake Lock API) 적용으로 스마트폰 주머니 속에서도 끊김 없는 기록
2. **실시간 지도 & 이동 경로 표시**
   - 현재 위치에 펄싱(Pulsing) 마커와 실시간 이동 경로(Polyline) 렌더링
   - Google Maps JavaScript API 연동 지원 + Leaflet(오픈스트리트맵) 기본 탑재로 별도 키 발급 없이도 즉시 완벽 작동
3. **운동 지표 실시간 계산 및 최종 리포트**
   - 🏁 **출발 시간 (Start Time)**
   - 🏁 **종료 시간 (End Time)**
   - ⏱️ **운동 시간 (Duration)**
   - 📍 **이동 거리 (km, 하버사인 공식 정밀 계산)**
   - 🔥 **소모 열량 (kcal, 종목별 MET 지수 기반 계산)**
   - ⚡ **페이스 (분:초 /km)**
4. **구글 스프레드시트 실시간 동기화**
   - 대상 시트: [구글 스프레드시트 바로가기](https://docs.google.com/spreadsheets/d/1JtuAIHo6TUqhZWT98ASbrG85IOHT96-uui8EzeK-9K4/edit?usp=sharing)
   - 운동 종료 시 11행 헤더 아래 12행부터 새로운 행으로 실시간 자동 추가
   - 앱 내 **[📊 실시간 시트 현황]** 탭에서 전체 참여 학생 수, 총 운동시간, 총 칼로리, 학생별 기록 목록을 실시간으로 확인 가능
5. **🏃‍♂️ 가상 달리기 시뮬레이션 모드 (실내/PC 테스트용)**
   - 지도 우측 상단의 달리기 아이콘(`🏃‍♂️`)을 누르면, 학교 운동장 400m 트랙을 실제로 달리는 것과 동일한 가상 GPS 좌표가 1초마다 생성되어 실내에서도 모든 기능과 수치 변화를 즉시 테스트할 수 있습니다.

## 🚀 빠른 시작 방법

### 1. 서버 실행
```bash
npm start
```
서버가 켜지면 브라우저에서 `http://localhost:3000` 으로 접속합니다.

### 2. 구글 스프레드시트 연동 (최초 1회, 1분 소요)
자세한 배포 절차는 [`google-sheets-script/README.md`](./google-sheets-script/README.md)에 상세히 정리되어 있습니다.
1. 스프레드시트 메뉴에서 **[확장 프로그램] ➜ [Apps Script]** 선택
2. [`google-sheets-script/Code.gs`](./google-sheets-script/Code.gs) 코드 전체를 복사하여 붙여넣고 저장
3. **[배포] ➜ [새 배포] ➜ [웹 앱]** 선택
   - 다음 사용자로 실행: `나(내 계정)`
   - 액세스 권한: **`모든 사용자(Anyone)`**
4. 배포 후 발급된 **웹 앱 URL**을 앱의 **[⚙️ 설정]** 탭에 붙여넣으면 연동 완료!

│   ├── Code.gs          # 구글 시트에 자동 기록하는 Apps Script 웹훅 코드

├── package.json         # 프로젝트 의존성 설정
