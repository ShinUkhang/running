# 🏃 학생 스마트 러닝 트래커 & 소셜 러닝 앱 (구글 스프레드시트 연동)

학생들이 스마트폰을 켜면 그 자리에서 즉석으로 가입하고, 전면 카메라로 **셀카 얼굴 사진을 찍어 나만의 달리기 캐릭터**를 생성합니다.  
지도 위에서 **친구들의 얼굴 캐릭터와 실시간 위치를 함께 보며 달릴 수 있으며**, 운동이 끝나면 출발/종료시간, 운동시간, 거리, 소모 열량, 페이스가 **구글 스프레드시트에 실시간으로 자동 기록**되는 멀티플레이어 러닝 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. ⚡ 현장 즉석 실시간 가입 & 참여
- 별도의 회원가입 절차 없이 이름, 학급(학년-반), 운동 종목만 입력하면 즉시 참여
- 로컬 스토리지 자동 저장으로 재접속 시 프로필 유지

### 2. 📸 전면 카메라 셀카 촬영 & 캐릭터 아바타 생성
- 스마트폰 카메라(`getUserMedia`)로 얼굴 사진을 찍으면 즉시 원형 스포츠 캐릭터로 가공
- 카메라를 사용할 수 없는 경우 귀여운 동물/로봇 이모지 프리셋(🐯, 🐰, 🦁, 🐼, 🤖) 선택 가능

### 3. 👥 친구들의 실시간 위치 & 캐릭터 마커 표시 (Socket.io)
- 같은 공간(학교 운동장, 트랙, 코스 등)에서 달리는 모든 학생들의 얼굴 캐릭터가 지도 위에 실시간으로 표시
- 친구들이 달릴 때마다 지도 위 캐릭터가 통통 튀며 실시간 이동
- 상단에 **[👥 친구 N명]** 실시간 접속자 수 표시
- 친구 캐릭터 터치 시 해당 학생의 학급, 이름, 현재 거리, 페이스 미니 팝업 표시

### 4. 📍 실시간 GPS 트래킹 및 화면 꺼짐 방지
- GPS 하버사인 정밀 거리 계산 및 GPS 노이즈 필터링
- 모바일 브라우저 주머니 속에서도 끊김 없는 기록을 위해 **화면 꺼짐 방지(Screen Wake Lock API)** 적용

### 5. 📊 운동 지표 실시간 계산 및 최종 리포트
- 🏁 **출발 시간 (Start Time)** & **종료 시간 (End Time)**
- ⏱️ **운동 시간 (Duration)** (1초 단위 대형 디지털 타이머)
- 📍 **이동 거리 (Distance km)**
- 🔥 **소모 열량 (Calories kcal)** (종목별 MET 지수 기반 체중 반영 계산)
- ⚡ **페이스 (Pace 분:초 /km)**

### 6. ☁️ 구글 스프레드시트 실시간 동기화
- 대상 시트: [구글 스프레드시트 바로가기](https://docs.google.com/spreadsheets/d/1JtuAIHo6TUqhZWT98ASbrG85IOHT96-uui8EzeK-9K4/edit?usp=sharing)
- 운동 종료 시 11행 헤더 아래(12행부터) 자동으로 새 행이 삽입되어 실시간 기록
- 앱 내 **[📊 실시간 시트 현황]** 탭에서 참여 학생 수(10명), 총 운동시간, 총 칼로리, 학생별 기록 목록을 실시간으로 확인 가능

### 7. 🏃‍♂️ 가상 달리기 시뮬레이션 모드 (실내/PC 테스트용)
- 지도 우측 상단의 달리기 아이콘(`🏃‍♂️`)을 누르면 400m 학교 트랙을 1초마다 도는 가상 GPS가 작동
- 친구들의 화면에서도 내 캐릭터가 운동장을 달리는 모습을 실내에서도 즉시 시연 가능

## 🚀 빠른 시작 방법

### 1. 서버 실행
```bash
npm start
```
서버가 켜지면 브라우저에서 `http://localhost:3000` 으로 접속합니다.  
(같은 와이파이에 연결된 스마트폰에서는 `http://[컴퓨터IP]:3000` 으로 접속 가능)

### 2. 구글 스프레드시트 연동 (최초 1회, 1분 소요)
- [`google-sheets-script/README.md`](./google-sheets-script/README.md) 안내에 따라 스프레드시트의 [확장 프로그램] ➜ [Apps Script]에 [`Code.gs`](./google-sheets-script/Code.gs)를 붙여넣고 웹 앱으로 배포합니다.
- 발급받은 웹 앱 URL을 러닝앱의 **[⚙️ 설정]** 탭에 등록하면 모든 학생의 기록이 자동 저장됩니다.

## 📁 프로젝트 구조

```
러닝앱/
├── public/
│   ├── index.html       # 러닝 트래커, 카메라 셀카 모달, 실시간 대시보드 UI
│   ├── style.css        # 캐릭터 마커, 카메라 뷰파인더, 스포츠 테마 반응형 CSS
│   └── app.js           # 카메라 촬영, Socket.io 멀티플레이어 동기화, GPS 로직
├── google-sheets-script/
│   ├── Code.gs          # 구글 시트에 자동 기록하는 Apps Script 웹훅 코드
│   └── README.md        # 1분 배포 가이드
├── server.js            # Node.js Express + Socket.io 실시간 멀티플레이어 서버
├── package.json         # 프로젝트 의존성 설정
└── README.md            # 전체 프로젝트 사용 설명서
```
