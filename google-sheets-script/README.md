# 📊 구글 스프레드시트 실시간 연동 가이드 (1분 완성)

학생들이 러닝앱에서 [운동 종료]를 누르면, 지정하신 구글 스프레드시트에 즉시 새로운 행으로 자동 기록되는 **Google Apps Script(웹훅)** 설정 방법입니다.

---

## 1. 스프레드시트에서 스크립트 열기
1. 대상 구글 스프레드시트 접속:
   👉 [스프레드시트 바로가기](https://docs.google.com/spreadsheets/d/1JtuAIHo6TUqhZWT98ASbrG85IOHT96-uui8EzeK-9K4/edit?usp=sharing)
2. 상단 메뉴에서 **[확장 프로그램]** ➜ **[Apps Script]** 를 클릭합니다.

---

## 2. 코드 붙여넣기
1. 기존에 적혀있는 코드가 있다면 모두 지웁니다.
2. 같은 폴더의 [`Code.gs`](file:///c:/Users/user/Desktop/자동화프로그램/러닝앱/google-sheets-script/Code.gs) 파일의 전체 내용을 복사하여 붙여넣습니다.
3. 상단의 💾 **[저장]** 아이콘(또는 `Ctrl + S`)을 누릅니다.

---

## 3. 웹 앱(Web App)으로 배포하기 (가장 중요!)
1. 오른쪽 상단 파란색 **[배포]** 버튼 ➜ **[새 배포]** 를 클릭합니다.
2. 왼쪽 톱니바퀴 아이콘(유형 선택)에서 **[웹 앱]** 을 선택합니다.
3. 설정을 다음과 같이 지정합니다:
   - **설명**: `러닝앱 연동`
   - **다음 사용자로 실행**: **`나(내 계정)`** (기본값)
   - **액세스 권한을 가진 사용자**: **`모든 사용자(Anyone)`** ⭐ (반드시 선택! 학생들이 구글 로그인 없이 즉시 기록을 전송하기 위해 필수입니다)
4. 하단의 **[배포]** 버튼을 클릭합니다.
5. (최초 1회 시) "액세스 승인" 창이 뜨면 **[액세스 승인]** ➜ 본인 구글 계정 선택 ➜ [Advanced/고급] 클릭 ➜ [Go to Untitled project (unsafe) / 안전하지 않은 페이지로 이동] 클릭 ➜ [Allow / 허용]을 누릅니다.

---

## 4. 웹 앱 URL을 러닝앱에 등록하기
1. 배포가 완료되면 화면에 **[웹 앱 URL]** 이 표시됩니다.  
   (형태: `https://script.google.com/macros/s/AKfycb.../exec`)
2. 해당 URL을 복사하여 러닝앱의 **[⚙️ 설정 & 가이드]** 탭 ➜ **[Google Apps Script 웹 앱 URL]** 입력칸에 붙여넣고 **[저장]** 을 누르면 끝입니다!

이제 모든 학생들의 운동 기록이 완료되는 즉시 스프레드시트의 12행 아래로 자동 저장됩니다!
